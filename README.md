# Turtles
Turtle Emotes for everyone \o/

## Welcome to the official TurtleLuv Emotes Server GitHub-Repo
Here you can find all the versions of the different emotes (SVG and PNG as well as templates) if given!

Thanks for stopping by!

## Just stumbled upon this... What is this?
**Turtles** is/was a project initiated by two teenagers (at the time) in 2017, hosted on a Discord server named *TurtleLuv*.

The images in this repo were mostly intended to be Discord emotes (when Nitro was first added).

Most of the SVGs were created using *GravitDesign* (now *Corel Vector*), which sucked because of its proprietary nature, though what was able to be salvaged was salvaged and turned into SVGs that can be opened in any vector application you want.

Most contributors had little experience, resulting in images that, while they can be used by everyone, are mostly inside jokes.

## You want to submit your own emote and want to do it over GitHub? You want to edit an emote?
Just make a Pull Request and explain why you want your changes to be saved! (Sometimes quite hard to identify on a small picture)
